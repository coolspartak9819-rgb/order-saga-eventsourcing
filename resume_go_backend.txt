ОСНОВНЫЕ ПРОЕКТЫ

ORDER SAGA & EVENT SOURCING IN GO
github.com/coolspartak9819-rgb/order-saga-eventsourcing

Сервис обработки заказов с отдельными платежным и складским сервисами. Состояние заказа формируется из доменных событий, а Saga управляет последовательностью действий и компенсацией при ошибках.

Go, PostgreSQL, database/sql, gRPC, Protocol Buffers, NATS JetStream, Kafka, Docker Compose.

QUEUE LENS
github.com/coolspartak9819-rgb/queuelens

Сервис для наблюдения за фоновыми задачами и очередями. Реализованы Redis Streams, consumer groups, retry policy, dead letter queue, отдельный worker и transactional outbox.

Также есть идемпотентность на PostgreSQL, rate limiting, request IDs, Prometheus, Grafana, Kafka-аудит, Kubernetes-манифесты и поддержка нескольких worker-реплик. Добавил pprof, latency histogram и benchmark со сбором RPS, p50, p95 и p99. В локальном прогоне 5000 запросов при concurrency 100 дали 3953 RPS, p95 34 мс и 100% ответов 202.

EDGEGATE NODE
github.com/coolspartak9819-rgb/edgegate-node

API Gateway и reverse proxy на Node.js 22. Реализованы балансировка Round Robin, Least Connections и Consistent Hashing, ограничение запросов через Redis Token Bucket, WAF, circuit breaker, health checks и динамическая загрузка middleware.

Есть нагрузочные проверки, Prometheus, Grafana, Kubernetes-манифесты и e2e-проверка отказа backend-инстанса. Отдельный chaos-сценарий проверяет остановку Redis и восстановление шлюза после запуска зависимости.
